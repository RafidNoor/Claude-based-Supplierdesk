Vercel Deployment Guide
  1. Create a free Redis database at console.upstash.com.
  2. In your Vercel Project dashboard, go to Settings > Environment Variables.
  3. Add UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN.
  4. Your users, products, drafts, and orders will persist across all serverless function invocations!

Why does "wrong version number" happen?

This OpenSSL error happens when "Use Direct SSL" is checked while using Port 587. Port 587 communicates via STARTTLS and requires SSL to be unchecked. Port 465 communicates via direct SSL and requires SSL to be checked. Our system will also auto-recover and correct this for you!
